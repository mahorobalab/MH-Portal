MHTranScreen

Lightweight utility for screen transparency and display assistance.

Overview

MHTranScreen is a lightweight Windows utility for screen transparency and display assistance, designed to support smooth streaming workflows and everyday desktop tasks.

Documentation in Progress: Detailed UI options, configuration settings, and shortcut references will be added once the project repository is linked.

Main Features

  • Screen transparency and visual display assistance
  • Lightweight operation that stays out of the way of your workflow
  • Lightweight, privacy-first design running strictly on your local device

Basic Usage

  1. Download and launch the app from BOOTH (Portable) or the Microsoft Store.
  2. Adjust the position and transparency settings according to your workflow.
  3. Toggle or fine-tune the display as needed while streaming or working.

Specifications & Requirements

Supported OS Windows 10 / Windows 11
Distribution BOOTH (Portable Edition) / Microsoft Store
Data Transmission None (local-only processing; version checks read a public JSON file on GitHub)
