MHTranSquare

Simple on-screen frame and region highlight utility for presentations and streams.

View on BOOTH (Portable) View on Microsoft Store
MHTranSquare Screenshot (16:9 Coming Soon)

Overview

MHTranSquare is a lightweight Windows utility that draws a clean, customizable frame around any area of your screen, making it easy to highlight key regions during livestreams, presentations, and screen sharing.

Documentation in Progress: Detailed UI options, configuration settings, and shortcut references will be added once the project repository is linked.

Main Features

  • Simple, distraction-free frame overlay to highlight specific screen regions
  • Intuitive controls suited for live presentations and video tutorials
  • Lightweight, privacy-first design running strictly on your local device

Basic Usage

  1. Download and launch the app from BOOTH (Portable) or the Microsoft Store.
  2. Resize and position the highlight frame over the screen area you want to emphasize.
  3. Use it during streams, recordings, or screen-sharing sessions to guide viewer attention.

Specifications & Requirements

Supported OS Windows 10 / Windows 11
Distribution BOOTH (Portable Edition) / Microsoft Store
Data Transmission None (local-only processing; version checks read a public JSON file on GitHub)
