Common Help & FAQ

SUPPORT / FAQ

General troubleshooting and setup instructions shared across Mahoroba Lab Windows utilities.

Q. Windows SmartScreen ("Windows protected your PC") appears when launching the BOOTH edition

Because the portable edition distributed on BOOTH is an independently published executable, Microsoft Defender SmartScreen may display a warning right after release or while download volume is still low.

After verifying that you downloaded the file directly from our official BOOTH page, follow these steps to launch the app:

  1. Click More info inside the SmartScreen dialog.
  2. Click Run anyway at the bottom of the window.

Once allowed, the warning will not appear on subsequent launches. Note that the Microsoft Store edition is signed and reviewed through the Store, so this warning does not appear.

Q. How do I capture and display transparent overlays properly in OBS Studio?

To composite our overlay utilities cleanly with a transparent background in OBS Studio, check your Window Capture or Game Capture properties:

  1. In OBS Sources, add a Window Capture source and select the target app window.
  2. If the window does not appear or transparency is not preserved, change Capture Method to Windows 10 (1903 and up).
  3. If Allow Transparency is available in the capture properties, enable it. When using Game Capture, check Allow Transparency in the source properties.

Please also refer to each app's individual Help & User Guide page for recommended per-app settings.

Q. How do I uninstall the applications?

The uninstallation method depends on how you installed the app:

  • BOOTH (Portable Edition): No installer or Windows registry entries are used. Simply close the application and delete the extracted folder to complete uninstallation.
  • Microsoft Store Edition: Open Windows Settings > Apps > Installed apps, locate the application, and select Uninstall.

Privacy Policy

POLICY / LOCAL-FIRST

How Mahoroba Lab Windows applications handle user data and network communication.

Read Privacy Policy (Local-only processing & GitHub version check details)

1. Local-Only Processing & Zero Data Collection

In all Windows applications provided by Mahoroba Lab, user keystrokes, screen regions, display information, and configuration settings are processed strictly on your local device. None of this data is ever transmitted to, stored on, or collected by any external server.

2. Network Requests for Version Checks

To check whether a newer version of the application is available, the app may perform a read-only HTTPS GET request to a public JSON file hosted on GitHub. No personally identifiable information or local user data is transmitted during this check.

3. Third-Party Sharing

Because our applications do not collect user data, no personal information is ever shared with or provided to third parties.

4. Contact & Updates

If you have any questions regarding this Privacy Policy, please contact us via our official X account (@mahorobalab). This policy may be updated without prior notice to reflect changes in laws or application specifications.
